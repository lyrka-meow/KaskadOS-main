# Пакетный репозиторий KaskadOS

Публичный адрес репозитория:

```text
https://repo.kaskados.xyz/x86_64/
```

Пакеты и база создаются локально на Arch Linux. GitHub Actions для публикации
не используются. Сервер получает только готовые подписанные файлы.

`kaskados-desktop` владеет файлами MacqueenDE, Regalia, графического менеджера
приложений, файлового менеджера и помощника обновлений. `dgop` поставляется
отдельным пакетом и является обязательной зависимостью рабочей среды. Благодаря
этому компоненты обновляются обычной полной командой обновления Pacman, без
повторной установки системы из ISO.

## Публикация пакетов

Для публикации требуется отдельный GPG-ключ KaskadOS. Его закрытая часть
остаётся только на компьютере разработчика.

```bash
export KASKADOS_SIGNING_KEY='<идентификатор ключа>'
./scripts/publish-repository.sh /полный/путь/к/пакету.pkg.tar.zst
```

Сценарий выполняет следующие действия:

1. копирует пакеты в `out/repository/x86_64`;
2. подписывает каждый пакет;
3. обновляет и подписывает `kaskados.db`;
4. синхронизирует готовый каталог с VPS.

Неподписанные пакеты и база не публикуются.

Рабочая среда и её пакет `dgop` собираются отдельно от ISO:

```bash
./scripts/build-desktop-package.sh
```

Готовые `kaskados-desktop-*.pkg.tar.zst` и `dgop-*.pkg.tar.zst` появляются в
`out/packages/x86_64/`. Публиковать нужно оба пакета. После публикации новой
версии пользователи получают их при обычном полном обновлении системы.

## Подключение в pacman

Подключать репозиторий в устанавливаемую систему можно только после создания
пакета `kaskados-keyring` с публичным ключом подписи. До этого добавлять секцию
`[kaskados]` в `pacman.conf` нельзя.
