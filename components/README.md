# Компоненты KaskadOS

## Calamares

Каталог `calamares/` содержит чистый снимок исходников Calamares:

- проект: <https://codeberg.org/Calamares/calamares>;
- ветка: `calamares`;
- commit: `841b478570c35261cd73e48c5aeb6acefd3db425`;
- дата импорта: 2026-08-15.

Исходники импортированы как обычные файлы, а не как Git submodule. Это позволяет
разрабатывать форк установщика прямо в репозитории KaskadOS. Вложенного `.git`
в каталоге нет, а лицензии и сведения об авторах сохранены из upstream.

Перед переносом будущих обновлений Calamares нужно сравнить новый upstream с
локальными изменениями KaskadOS и применить только совместимые изменения.

## Kaskad Installer compositor

Каталог `kaskad-installer-compositor/` содержит снимок композитора Macqueen,
предназначенный только для графической live-сессии установщика KaskadOS:

- проект: <https://github.com/lyrka-meow/MacqueenDE>;
- исходный каталог: `compositor/`;
- ветка: `main`;
- tag: `rolling`;
- commit: `a9759b679a1ade4873562e081384860e617e29f8`;
- дата импорта: 2026-08-21.

Исходники импортированы как обычные файлы без вложенного `.git`. Репозиторий
MacqueenDE при переносе не изменяется. В KaskadOS публичное имя, конфигурация и
состав сборки отделяются от Macqueen, потому что эта копия обслуживает только
полноэкранную live-сессию Calamares.

Обновления Macqueen нужно переносить сравнением с указанным commit. Нельзя
заменять каталог вслепую: локальные изменения имени, запуска и kiosk-режима
являются частью архитектуры KaskadOS.

## Темы установщика

Каталог `installer-themes/` содержит локальные копии выбранных тем GRUB и
SDDM, а также их превью. Они встраиваются в ISO и не скачиваются во время
установки. Точные исходные репозитории и commit для каждого набора записаны в
`installer-themes/SOURCES.md`.

Calamares переносит в установленную систему только выбранную тему. Остальной
набор и превью остаются только в live-среде.
